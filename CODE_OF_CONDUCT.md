# Code of conduct

Oathe follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work rather than people, and keep the project a reasonable place to disagree. Technical rigor and personal decency are not in tension here; we expect both.

## Reporting

Report conduct issues privately to the maintainers at info@oathe.ai. Do not use public issues for conduct reports.

Reports are reviewed by maintainers who are not the subject of the report. Consequences follow the Contributor Covenant enforcement ladder: correction, warning, temporary ban, permanent ban.

## Scope

This code applies in all project spaces — issues, pull requests, discussions, and any venue where someone is representing the project.
